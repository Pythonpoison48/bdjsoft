# Repository pour les scripts/ressources du BDJ (Association de jeux/{vidéo,société,plateau,wargame} de l'ESIEA

## AUTOISO 

### Description
Petit outil en tcl permettant de créer des iso de windows XP custom
### Deps

- Magicsplat
- 7zip
- oscdimg
```powershell
winget install -e --id Magicsplat.TclTk
winget install -e --id Microsoft.OSCDIMG
winget install -e --id 7zip.7zip
```
